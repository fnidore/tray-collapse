这次更新主要改进顶栏样式、收放动画和日常使用的稳定性。

## 图标与交互

- 折叠按钮改为简洁的单箭头：`‹` 展开，`›` 收起。去掉底座、边框和橙色装饰，悬停时轻微提亮。
- 图标画布放大到 22px，让可见图形与旁边的托盘图标更协调，颜色继续跟随主题。
- 新增两段动画：展开约 220ms，向左舒展并淡入；收起约 160ms，向按钮收回并淡出。快速连点可以反向切换，关闭桌面动画后直接切换状态。
- 支持 Enter / 空格切换，按钮获得焦点时按 Esc 收起；读屏名称同步提示当前可执行的动作。

## 稳定性修复

- 修复收放动画引起右侧图标快速闪烁和抖动的问题。动画期间保持布局宽度不变，只改变裁剪区域和透明度，避免反复重新排版和像素取整跳动。
- 修复程序退出后遗留空白间隔和失效引用的问题。
- 禁用扩展时恢复图标原来的面板区域、相邻位置和内联样式；支持 AppIndicator 将图标移动到左、中、右任一区域后重新收纳。
- 修复旧配置迁移触发重复扫描的问题；合并 legacy 重复记录时保留已知同名应用之间的区分关系，多个同名图标在线时不猜测旧记录的归属。

## 设置与安装

- 设置窗口实时同步新图标、默认行为、逐个图标的选择和间距，无需关闭重开。
- 增加图标配置结构校验，避免损坏记录导致扩展或设置窗口报错；正确显示标题中的特殊字符。
- 源码安装、卸载脚本只处理软链接，遇到普通目录或文件时拒绝直接覆盖、删除。
- deb 依赖范围限制为 GNOME Shell 42，与扩展声明的兼容范围保持一致。

## 安装与升级

兼容范围：**Ubuntu 22.04 / GNOME Shell 42 / X11**，需要启用 AppIndicator 扩展。其他 GNOME 版本和 Wayland 未验证。

按原来的安装方式选择一个包：

**zip：**

```bash
gnome-extensions install --force ./tray-collapse@fnidore.top.shell-extension.zip
```

**deb：**

```bash
sudo apt install ./gnome-shell-extension-tray-collapse_3_all.deb
```

安装后，在 X11 下按 `Alt+F2`，输入 `r` 并回车，重载 GNOME Shell；如尚未启用扩展，再执行：

```bash
gnome-extensions enable tray-collapse@fnidore.top
```

源码软链安装的用户可更新项目后重载 Shell，无需另外安装 zip 或 deb。
